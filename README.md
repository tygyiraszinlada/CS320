## CS 320 Software Testing, Automation and Quality Assurance

In this course, I worked on creating and testing different services for a mobile application. For Project One, I developed the contact, task and appointment services and used JUnit tests to make sure they followed the requirements. For Project Two, I reflected on my testing approach and what I learned throughout the course.

### How can I ensure that my code, program or software is functional and secure?

I can make sure my code is functional and secure by testing it regularly and checking that it follows the requirements. Throughout this course, I used JUnit to test valid and invalid information, including null values, incorrect lengths and duplicate IDs. I also checked code coverage to see how much of my code was being tested. This helped me catch problems and make sure the program handled unexpected inputs correctly.

### How do I interpret user needs and incorporate them into a program?

I start by looking at the requirements and figuring out what the program needs to do. For example, the contact service had specific rules for IDs, names, phone numbers and addresses. I used those requirements to build the program and create tests to verify everything worked correctly. I think understanding what the user expects is important because even if a program runs without errors, it might not actually do what the user needs.

### How do I approach designing software?

When designing software, I try to keep things organized and simple instead of making them more complicated than necessary. For these projects, I separated the objects from the services that manage them, which made the code easier to understand and test. I also tried to make each test focus on one requirement so it was easier to find problems. Going forward, I want to continue planning around the requirements and testing my code as I develop it instead of waiting until the end.
